Microsoft மற்றும் OpenAI இடையே ஆழமான ஒத்துழைப்பு பற்றிய சமீபத்திய செய்திகளால் உரையாடல் AI உலகம் உற்சாகமடைகிறது. சிலர் இந்த ஒத்துழைப்பின் திறனைக் கொண்டாடுகிறார்கள், ஆனால் Microsoft உள்ளேயும் அதிருப்தியின் குரல்கள் உள்ளன. உள்வட்ட வட்டாரங்கள் OpenAI தயாரிப்புகளை ஊக்குவிக்க உள் AI மேம்பாட்டிலிருந்து விலகுவதைப் பற்றி கவலைப்படுவதாக அறிக்கைகள் கூறுகின்றன.

குறிப்பாக குறிப்பிடப்பட்ட பகுதி Microsoft Azure Bot Service இன் விதி. உள்வட்ட செய்தி ஆதாரங்கள், அது "[குறைவாகவோ அல்லது அதிகமாகவோ மறைந்துவிட்டது](https://www.digitalinformationworld.com/2024/03/microsoft-insiders-fear-firm-has.html)" என்று குறிப்பிடுகின்றன, OpenAI தீர்வுகளால் மாற்றப்பட்டுள்ளது.

[Microsoft Bot Framework](https://dev.botframework.com/) மற்றும் [Azure AI Bot Service](https://azure.microsoft.com/en-us/products/ai-services/ai-bot-service) (மேலும் [LUIS.ai](http://LUIS.ai)) என்பவை நீங்கள் புத்திசாலி ரோபோக்களை உருவாக்க, சோதிக்க, வெளியிட மற்றும் நிர்வகிக்க உதவும் நூலகங்கள், கருவிகள் மற்றும் சேவைகளின் தொகுப்பாகும். இருப்பினும், [Bot Framework SDK இன் GitHub களஞ்சியம்](https://github.com/microsoft/botframework-sdk) 2 ஆண்டுகளுக்கும் மேலாக (2024 வரை) README தவிர வேறு எந்த புதுப்பிப்பும் இல்லை:

## Microsoft Bot Framework க்கான மாற்று என்ன?

SeaChat வருகிறது: **LLM சவாலாளி**

Microsoft தனது AI உத்தியைப் பற்றி சிந்திக்கும்போது, Seasalt.ai தனது LLM (பெரிய மொழி மாதிரிகள்) இயக்கப்படும் உரையாடல் தளமான [SeaChat](https://chat.seasalt.ai/?utm_source=blog) மூலம் கவனத்தை ஈர்க்கிறது. SeaChat இயற்கை மொழி புரிதலின் சமீபத்திய முன்னேற்றங்களைப் பயன்படுத்தி, பாரம்பரிய விதி அடிப்படையிலான சாட்போட்களை விட மிகவும் இயற்கையான மற்றும் உள்ளுணர்வு பயனர் அனுபவத்தை வழங்குகிறது.

**SeaChat உரையாடல் AI புரட்சியை வழிநடத்த நன்கு நிலைப்படுத்தப்பட்டிருக்கலாம் ஏன்**:
- **LLM சக்தி**:
  LLM சக்தியைப் பயன்படுத்தி, மிகவும் நுணுக்கமான உரையாடலை ஊக்குவிக்கிறது.
  சூழல் மற்றும் நோக்கத்தை மிகவும் துல்லியமாக புரிந்துகொள்கிறது.
  பயனர் தொடர்புகளை மிகவும் இயற்கையான மற்றும் சிறந்ததாக மாற்றுகிறது.
- **நெகிழ்வுத்தன்மை**:
  பயனர்களுடன் தொடர்பு கொள்ளும்போது தழுவி கற்றுக்கொள்கிறது.
  தொடர்புடைய மற்றும் பயனுள்ள பதில்களை வழங்கும் திறனை தொடர்ந்து மேம்படுத்துகிறது.
  காலப்போக்கில் சிக்கலான வினவல்கள் மற்றும் கோரிக்கைகளை கையாளுகிறது.
- **தடையற்ற ஒருங்கிணைப்பு**:
  பல்வேறு தளங்கள் மற்றும் பயன்பாடுகளுடன் தடையற்ற ஒருங்கிணைப்பு.
  பல்வேறு சேனல்களில் சாட்போட்களை எளிதாக வெளியிடுதல்.
  ஒருங்கிணைந்த வாடிக்கையாளர் அனுபவத்திற்கான அனைத்து சேனல் ஆதரவு.
- **குறைக்கப்பட்ட மேம்பாட்டு நேரம்**: குறைந்த குறியீடு தேவைகளுடன் சிக்கலான சாட்போட்களை உருவாக்குதல்.
- **செலவு செயல்திறன்**: பெரிய பயிற்சி தரவு மற்றும் வளங்களின் தேவையை நீக்குகிறது.
- **அளவிடக்கூடிய தன்மை**: செயல்திறனை பாதிக்காமல் அதிக அளவு வினவல்களை எளிதாக கையாளுதல்.

## Azure Bot Service மற்றும் Microsoft Bot Framework இன் குறைபாடுகள்
Azure Bot Services மற்றும் Microsoft Bot Framework தங்கள் பயன்பாடுகளைக் கொண்டிருந்தபோதிலும், அவை சில குறைபாடுகளைக் கொண்டுள்ளன:
- **விதி அடிப்படையிலான வரம்புகள்**: முன்கூட்டியே வரையறுக்கப்பட்ட விதிகளை நம்பியிருப்பது கடினமான உரையாடலுக்கு வழிவகுக்கலாம், எதிர்பாராத பயனர் உள்ளீட்டை கையாளுவது கடினம்.
- **மேம்பாட்டு சிக்கலான தன்மை**: சிக்கலான சாட்போட்களை உருவாக்குவதும் பராமரிப்பதும் குறிப்பிடத்தக்க குறியீடு நிபுணத்துவத்தை தேவைப்படுத்தலாம்.
- **வரையறுக்கப்பட்ட அளவிடக்கூடிய தன்மை**: அதிக அளவு வினவல்களை நிர்வகிப்பது சவாலாக மாறலாம், செயல்திறனை பாதிக்கலாம்.
- **ஒருங்கிணைப்பு சவால்கள்**: பல்வேறு தளங்களுடன் ஒருங்கிணைப்பு கூடுதல் மேம்பாட்டு வேலையை தேவைப்படுத்தலாம்.
- **விற்பனையாளர் பூட்டு**: Microsoft சுற்றுச்சூழலை நம்பியிருப்பது நெகிழ்வுத்தன்மை மற்றும் எதிர்கால தேர்வுகளை வரையறுக்கலாம்.
- **OpenAI உடனான நிச்சயமற்ற எதிர்காலம்**: Microsoft OpenAI தீர்வுகளுக்கு மாறுவது Bot Framework நீண்ட கால ஆதரவில் நிச்சயமற்ற தன்மையை உருவாக்குகிறது.

## பாரம்பரிய நோக்கம்/நிறுவன அடிப்படையிலான NLU vs LLM அடிப்படையிலான NLU ஒப்பீடு

நோக்கம்/நிறுவன அடிப்படையிலான NLU மற்றும் LLM அடிப்படையிலான NLU இடையேயான வேறுபாடு [மில்லியன் கணக்கில்](https://seasalt.ai/blog/73-intent-entity-based-nlu-vs-genai-llm-based-nlu/?utm_source=blog) உள்ளது என ஆராய்ச்சி காட்டுகிறது. பயிற்சி உதாரணங்களின் அடிப்படையில், 630,000 உதாரணங்கள் vs வெறும் 32. பயிற்சி தரவு தேவைகளில் இந்த கடுமையான குறைப்பு GenAI/LLM அடிப்படையிலான NLU ஐ ஏற்றுக்கொள்வதில் வணிகங்களுக்கு குறிப்பிடத்தக்க செலவு சேமிப்பாக மாற்றுகிறது.

## SeaChat சிறந்த உரையாடல் அனுபவத்தை வழங்க முடியும்
SeaChat உரையாடல் AI துறையில் குறிப்பிடத்தக்க முன்னேற்றத்தை குறிக்கிறது, கவர்ச்சிகரமான மற்றும் தனிப்பட்ட உரையாடல் அனுபவங்களை உருவாக்க வணிகங்களுக்கு சக்திவாய்ந்த மற்றும் பல்துறை தளத்தை வழங்குகிறது. அதன் மேம்பட்ட தொழில்நுட்பம், தடையற்ற ஒருங்கிணைப்பு மற்றும் விரிவான செயல்பாட்டு தொகுப்புடன், [SeaChat](https://chat.seasalt.ai/?utm_source=blog) Azure Bot Services மற்றும் Microsoft Bot Framework போன்ற பாரம்பரிய கட்டமைப்புகளுக்கு சக்திவாய்ந்த மாற்றாக, AI இயக்கப்படும் தொடர்புகளுக்கான எதிர்காலத்திற்கான வழியை அமைக்கிறது.
