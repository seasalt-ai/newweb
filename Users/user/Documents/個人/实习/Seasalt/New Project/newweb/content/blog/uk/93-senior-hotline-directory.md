У міру старіння суспільства доступ до гарячих ліній для літніх людей та доступних послуг з догляду за літніми людьми стає все більш важливим. Зі зростанням кількості літніх людей життєво важливо мати надійні ресурси для негайної допомоги та постійної підтримки. Цей збірник має на меті допомогти літнім людям та їхнім родинам легко знайти необхідні ресурси для догляду у великих містах та округах Тайваню.

## Розуміння потреб у догляді за літніми людьми

Своєчасний доступ до цілодобових гарячих ліній Департаменту соціальних справ та екстрених служб є критично важливим для забезпечення добробуту літніх людей. Згідно з презентацією продукту Seasalt.ai, зменшення навантаження на волонтерів при збереженні високої якості послуг є ключовим для підтримки довгострокових зусиль з догляду. Використовуючи передові технології, такі як автоматизовані дзвінки для догляду за літніми людьми та голосові боти, ми можемо оптимізувати рутинні завдання, дозволяючи постачальникам послуг зосередитися на наданні персоналізованої підтримки тим, хто її потребує.

Для отримання додаткової інформації про послуги довгострокового догляду рекомендується звернутися безпосередньо до відділу довгострокового догляду Міністерства охорони здоров'я та соціального забезпечення. Будь ласка, відвідайте [Послуги довгострокового догляду Міністерства охорони здоров'я та соціального забезпечення](https://1966.gov.tw/).

## Доступні послуги з догляду в кожному місті та окрузі:

### Тайбей

Тайбей пропонує широкий спектр послуг з догляду, адаптованих до різноманітних потреб літніх людей. Місто має цілодобову екстрену гарячу лінію: 1999, що гарантує, що літні люди можуть отримати допомогу в будь-який час, коли вона їм потрібна. Крім того, Тайбей є домом для численних громадських центрів та організацій підтримки, які надають щоденну допомогу, соціальні заходи та медичні послуги.

Для отримання додаткової інформації про Департамент соціальних справ Тайбея, будь ласка, відвідайте [Департамент соціальних справ Тайбея](https://dosw.gov.taipei/).

### Новий Тайбей

Місто Новий Тайбей не тільки надає базові послуги з догляду за літніми людьми, але й створило цілодобову лінію обслуговування для надзвичайних ситуацій: 02-29603456. Департамент соціальних справ міста також надає психологічну підтримку та консультації з питань здоров'я, щоб допомогти літнім людям впоратися з різними викликами.

Для отримання додаткової інформації про Департамент соціальних справ Нового Тайбея, будь ласка, відвідайте [Департамент соціальних справ Нового Тайбея](https://www.sw.ntpc.gov.tw/).

### Тайчжун

У Тайчжуні Департамент соціальних справ відіграє ключову роль у підтримці літніх громадян міста. Літні люди можуть отримати допомогу через послуги департаменту, які включають консультування, догляд на дому та гарячу лінію для скарг соціальних працівників: 04-22289111. Місто також підкреслює важливість психічного здоров'я та добробуту, пропонуючи такі ресурси, як гаряча лінія з деменції: 0800-474-580 та особисту підтримку.

Для отримання додаткової інформації про Департамент соціальних справ Тайчжуна, будь ласка, відвідайте [Департамент соціальних справ Тайчжуна](https://www.society.taichung.gov.tw/880452/post).

### Таоюань

Місто Таоюань також надає пріоритет догляду за літніми людьми, пропонуючи широкий спектр медичних та соціальних послуг підтримки. Цілодобова екстрена гаряча лінія міста: 03-3333001 має на меті надати швидку та ефективну допомогу літнім людям, забезпечуючи негайну підтримку, коли це необхідно.

Для отримання додаткової інформації про Департамент соціальних справ Таоюаня, будь ласка, відвідайте [Департамент соціальних справ Таоюаня](https://sab.tycg.gov.tw/).

### Тайнань

Тайнань пропонує комплексні послуги з догляду за літніми людьми, включаючи медичні огляди, допомогу в повсякденному житті та соціальні заходи. Гаряча лінія для літніх людей міста: 06-2991111 спеціально розроблена для літніх людей, надаючи цілодобову допомогу та підтримку.

Для отримання додаткової інформації про Департамент соціальних справ Тайнаня, будь ласка, відвідайте [Департамент соціальних справ Тайнаня](https://sab.tainan.gov.tw/).

### Гаосюн
Гаосюн прагне покращити якість життя своїх літніх громадян. Місто пропонує комплексні послуги, включаючи охорону здоров'я, соціальну підтримку та екстрену гарячу лінію: 07-3368333. Літні люди в Гаосюні можуть покладатися на ці ресурси для екстрених потреб та постійного догляду, забезпечуючи їм належний догляд та підтримку.

Для отримання додаткової інформації про Департамент соціальних справ Гаосюна, будь ласка, відвідайте [Департамент соціальних справ Гаосюна](https://socbu.kcg.gov.tw/).
