# Schema Implementation Summary - Zapier Integration Pages

## Overview
Successfully implemented proper ld+json schema for all Zapier integration pages following the hub-spoke model (`/[lang]/integrations/[app]/[action]`).

## Changes Made

### 1. Fixed Variable Placeholder Issue ✅
**Problem:** Meta titles and keywords were showing literal `{appName}` and `{actionName}` instead of actual values.

**Root Cause:** Using `.replace()` only replaces the **first occurrence** of a placeholder. Since the translation strings have multiple occurrences (e.g., `"{appName} to {actionName} Integration | Automated {actionName} from {appName}"`), the second occurrences were not being replaced.

**Solution:** Changed all `.replace()` calls to `.replaceAll()` throughout the file.

**Files Modified:**
- `src/pages/[lang]/integrations/[app]/[action].astro`

**Locations Fixed:**
- Lines 44-54: SEO metadata (title, description, keywords)
- Line 152: Hero headline translation
- Line 169: How it works step 1 description
- Line 347: Other channels section title
- Line 378: Final CTA title

### 2. Implemented Proper ld+json Schemas ✅

#### A. SoftwareApplication Schema
- **Purpose:** Represents the integration itself as a software application
- **Name Format:** `"${app.name} to ${action.name} Integration | Automated ${action.name} from ${app.name}"`
- **Features:**
  - Cloud-based operating system
  - Business application category
  - Free trial offer ($0.00)
  - Aggregate rating (4.8/5 with 500 reviews)
  - Specific integration URL

#### B. HowTo Schema
- **Purpose:** Provides step-by-step setup instructions for SEO rich results
- **Name Format:** `"How to connect ${app.name} to ${action.name} using Seasalt.ai"`
- **Features:**
  - 5-minute estimated time (PT5M)
  - Three required tools listed
  - Four detailed steps with images and anchor links
  - App-specific images from `public/app_images/`
  - Falls back to Seasalt.ai icon if app image missing

#### C. BreadcrumbList Schema
- **Status:** Automatically generated by SEO component
- **Action Taken:** Removed duplicate schema to prevent duplicate breadcrumb listings
- **How It Works:** SEO component generates BreadcrumbList from the `breadcrumbs` prop

### 3. Fixed Build Error ✅
**Problem:** Build failing with error: `"getTranslation" is not exported`

**Solution:** Changed import in `/integrations/index.astro` from `getTranslation` to `getTranslationHelpers`

**Files Modified:**
- `src/pages/[lang]/integrations/index.astro`

## Technical Details

### String Replacement Pattern
```javascript
// ❌ OLD (only replaces first occurrence)
const title = t('integrations.spoke.metaTitle')
  .replace('{appName}', app.name)
  .replace('{actionName}', action.name);

// ✅ NEW (replaces all occurrences)
const title = t('integrations.spoke.metaTitle')
  .replaceAll('{appName}', app.name)
  .replaceAll('{actionName}', action.name);
```

### Schema Injection Pattern
```javascript
// Schemas are defined in frontmatter
const customJsonLd = [integrationSchema, howToSchema];

// Passed to Layout component
<Layout 
  title={title}
  description={description}
  customJsonLd={customJsonLd}
  breadcrumbs={breadcrumbs}
  ...
/>
```
