## 🌐 多語言系統

### 支援的語言 (20種語言)
- 英語 (en) - 主要語言
- 繁體中文 (zh-TW) - 目前主要開發語言
- 簡體中文 (zh-CN)
- 西班牙語 (es), 法語 (fr), 德語 (de)
- 日語 (ja), 韓語 (ko)
- 阿拉伯語 (ar), 波斯語 (fa)
- 印地語 (hi), 泰語 (th), 越南語 (vi)
- 印尼語 (id), 馬來語 (ms), 菲律賓語 (fil)
- 泰米爾語 (ta), 波蘭語 (pl), 葡萄牙語 (pt), 俄語 (ru)

### i18n 功能
- **技術棧**：i18next + react-i18next + i18next-browser-languagedetector + i18next-http-backend
- **語言偵測**：自動偵測瀏覽器語言
- **語言切換器**：Header 中的語言選擇下拉選單
- **URL 路由**：`/{lang}/page` 格式，例如 `/zh-TW/seachat`
- **預設語言**：英語 (en)
- **翻譯檔案位置**：`public/locales/{lang}/translation.json`

### 語言路由邏輯
- 根路徑 `/` 自動重導向到偵測的瀏覽器語言
- 無語言前綴的路徑自動重導向到預設語言版本
- 語言前綴錯誤或不支援時重導向到預設語言

## 🔍 SEO 功能

### SEO 組件和工具
- `SEOHelmet` - 基於 react-helmet-async 的 SEO 管理
- `FaviconManager` - Favicon 管理
- `GTMTracker` - Google Tag Manager 追蹤
- `UTMTracker` - UTM 參數追蹤

### SEO 功能
- **動態 Meta 標籤**：title, description, keywords
- **Open Graph 標籤**：Facebook, Twitter 分享優化
- **結構化資料**：Schema.org 標記
- **Canonical URLs**：規範化網址
- **多語言 hreflang**：語言替代標籤
- **網站地圖**：自動生成 sitemap.xml
- **Robots.txt**：搜尋引擎爬蟲指示

### SEO 腳本
- `generate-sitemap.js` - 網站地圖生成
- `generate-robots.js` - robots.txt 生成
- `seo-analyzer.mjs` - SEO 分析工具
