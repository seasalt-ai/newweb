## 🔧 **技術實現細節**

### **路由系統**
- **Astro 檔案式路由**: `src/pages/[lang]/[page].astro`
- **動態語言參數**: `[lang]` 支援 20 種語言
- **靜態生成**: 每個頁面生成 20 個語言版本

### **連結生成規則**
```typescript
// 內部連結 (相對路徑)
`/${currentLang}/pricing`             # 定價頁面
`/${currentLang}/channels/whatsapp`   # WhatsApp 渠道頁面

// 外部連結 (絕對 URL)  
`https://seax.seasalt.ai/signup`      # SeaX 註冊
`https://seameet.ai/`                 # SeaMeet 產品
```

### **SEO 和技術考量**
- **Canonical URLs**: 每個頁面設定規範網址
- **hreflang 標籤**: 多語言 SEO 最佳化
- **sitemap.xml**: 自動生成網站地圖
- **RSS feeds**: Blog 系統 RSS 訂閱

## 🎯 **使用指南**

### **對於開發者**
1. **新增頁面**: 在 `src/pages/[lang]/` 建立 `.astro` 檔案
2. **連結引用**: 使用 `/${currentLang}/[path]` 格式
3. **翻譯支援**: 在 `src/i18n/locales/` 中加入翻譯鍵

### **對於內容管理者**
1. **更新連結**: 修改對應的 `.astro` 檔案
2. **新增語言**: 擴展 `supportedLanguages` 陣列
3. **SEO 優化**: 更新每頁的 meta 標籤和結構化資料
